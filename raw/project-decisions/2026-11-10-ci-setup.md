# Decision: CI setup (GitHub Actions)

> Source: own design note; user asked for "GitHub Actions CI with `lake check` (and all other things a Lean project of this type needs/should have)"
> Collected: 2026-11-10
> Published: 2026-11-10

- `.github/workflows/ci.yml` on push to main, PRs, manual. Jobs:
  - lean: leanprover/lean-action v1.7.1 (SHA ba3fdfe5) with `build-args: --wfail`, `leanchecker: true`, `axiom-audit: true` (allowlist propext, Classical.choice, Quot.sound); then install bubblewrap, run scripts/setup-bwrap-apparmor.sh, then `lake check`.
  - forbidden: scripts/check_forbidden.py (source grep with comments and strings stripped): sorry, admit, native_decide, bv_decide, ofReduceBool, reduceBool, trustCompiler, implemented_by, extern, new axiom, debug.* options. Catches what axiom audits cannot (implemented_by, extern, debug options).
  - wiki: scripts/check_wiki.py (broken links, index coverage, Sources line, nesting; unreferenced raw files are warnings).
- `.github/workflows/paranoid.yml` weekly (Mon 03:17 UTC) + manual: lean-action with nanoda (nanoda-allow-sorry false), then `lake check --paranoid`. Not on every push because it takes >2 min on the empty scaffold.
- `.github/dependabot.yml`: weekly github-actions updates (lean-action README recommends it because old lean-action versions break with new Lean).
- Actions pinned by commit SHA with version comment (checkout v7.0.1 = 3d3c42e5, lean-action v1.7.1 = ba3fdfe5).
- Not included yet (no need on the scaffold): `lake test` driver (lean-action runs it automatically once one exists), `lake lint` (needs Batteries linter), Mathlib cache (no Mathlib), difftest job (no harness yet), `mk_all --check`.
- Local test: check_forbidden.py found all 6 planted violations and ignored ones in comments, nested comments, strings, a primed name and `sorryish`; check_wiki.py found a planted broken link, missing index entry and missing Sources line.
